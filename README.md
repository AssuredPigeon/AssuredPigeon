### 🎯 Proyectos que he construido

#### → Bot musical inteligente
Un bot de Discord que no solo reproduce música, sino que entiende comandos de voz y recomienda canciones. Usa Whisper para reconocimiento de voz y modelos de lenguaje para entender qué quieres escuchar.

#### → Compilador desde cero
Porque entender cómo funciona un lenguaje de programación es construir uno. Análisis léxico, sintáctico, semántico... todo en Python.

#### → Juego de mecanografía
Pygame meets educación. Un juego donde mejoras tu velocidad de escritura mientras combates enemigos y desbloqueas power-ups.

#### → Sistema de tracking corporal VR
MediaPipe + OpenCV para seguimiento de manos y cuerpo en tiempo real. Experimentando con interacciones en realidad virtual.

#### → Apps móviles multiplataforma
React Native para crear experiencias móviles. Porque el código debería escribirse una vez y funcionar en todas partes.
