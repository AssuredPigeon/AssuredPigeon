## Sobre mí

Soy desarrollador de software con experiencia práctica en Inteligencia Artificial y modelos de lenguaje (LLMs).
He integrado y evaluado sistemas de IA —incluyendo Google Gemini API y OpenAI Whisper— en proyectos reales, analizando sus respuestas con criterio técnico en términos de precisión, coherencia, sesgo y utilidad.

Me especializo en el desarrollo backend y en el diseño de sistemas donde la arquitectura, el flujo de datos y la toma de decisiones son elementos clave.
Cuento con 257 horas certificadas en IA (Guayerd & IBM SkillsBuild, 2024) y actualmente curso el 6.° semestre de Ingeniería en Software en la UABC.

## Proyectos Destacados

<details>
<summary><b>Vialix — Plataforma de Detección de Baches</b></summary>
<br>

Plataforma para detectar y mapear baches en tiempo real usando datos de acelerómetro y geolocalización.

**Características principales:**
- API REST completa (+30 endpoints) con lógica ML para calcular índices de calidad vial basados en densidad de anomalías
- Deduplicación geoespacial con **PostGIS** para filtrar falsos positivos en datos del acelerómetro
- Rol de Lead Backend / ML en el proyecto

**Stack:** `Node.js` `PostgreSQL` `PostGIS` `Supabase` `React Native`

</details>

<details>
<summary><b>Semantic Visualization — Plataforma de Visualización Semántica</b></summary>
<br>

Plataforma de investigación para visualizar y analizar el proceso de entrenamiento de modelos de aprendizaje automático,
permitiendo observar la evolución semántica de los datos a lo largo de las generaciones.

**Características principales:**
- Integración con **Google Gemini API** para generar interpretaciones automáticas en lenguaje accesible, con prompt engineering iterativo para mejorar precisión y coherencia
- Visualización de datasets en **2D y 3D** usando la generación como eje temporal
- Métodos de reducción de dimensionalidad: PCA, t-SNE, Kernel PCA, UMAP
- Identificación de limitaciones del LLM en contextos matemáticos específicos

**Stack:** `Python` `Flask` `Google Gemini API` `PCA` `t-SNE` `UMAP` `Plotly` `ReportLab`

</details>

<details>
<summary><b>Bot de Música con Control de Voz para Discord</b></summary>
<br>

Sistema inteligente de reproducción musical con reconocimiento de voz desplegado en la nube.

**Características principales:**
- Implementación y evaluación de **OpenAI Whisper**, iterando múltiples enfoques tras identificar limitaciones en distintos contextos de ruido y acento
- Motor de recomendaciones musicales basado en historial de usuario
- Gestión de base de datos con **SQLite + Tortoise ORM**
- Desplegado en **Oracle Cloud** con Docker

**Stack:** `Python` `Discord.py` `OpenAI Whisper` `Flask` `SQLite` `Docker` `Oracle Cloud`

</details>

<details>
<summary><b>SDGKU — Sistema de Gestión Universitaria</b></summary>

**Stack:** `NestJS` `TypeScript` `Prisma` `MySQL` `Alpine.js`

</details>
