<summary><b>🎵 INTELLIGENT DISCORD MUSIC BOT</b></summary>

<br>

> **Next-generation music bot powered by artificial intelligence**

**The Challenge:**  
Traditional music bots require exact commands. I wanted something that understands natural language.

**The Solution:**  
Built an AI-powered bot that processes voice commands, understands user intent, and provides intelligent music recommendations.

**Tech Stack:**
- 🎤 **Whisper** → Voice recognition
- 🧠 **BERT Models** → Intent analysis
- 💾 **SQLite + Tortoise ORM** → Data persistence
- 🎯 **Custom Recommendation Engine** → Smart suggestions

**Impact:** Users can speak naturally and get exactly what they want to hear.

</details>
